# Hair Lab

Официальный статический сайт студии Hair Lab в Томске, опубликованный через GitHub Pages.

## Основные страницы

- `index.html` — главная страница;
- `price.html` — актуальный прайс.

## Структура

- `studio.css` — стили главной страницы и прайса;
- `masters/` — фотографии мастеров;
- `PriceMay2026/` — полноразмерные карточки актуального прайса;
- `PriceMay2026/thumbs/` — оптимизированные WebP-превью;
- `robots.txt`, `sitemap.xml`, `og.png` — SEO и изображение для соцсетей.

Публикация выполняется из ветки `main` на <https://hairlab1.github.io/>.
